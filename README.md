Lecture 7 practice for data management and GitHub synchronisation.

## Purpose

This repository contains a small exercise in recording changes and synchronising files between a local computer and GitHub.

## Data management notes

- Keep original data separate from processed files.
- Describe variable names, units and processing decisions in a README.
- Use clear commit messages so changes can be followed.
